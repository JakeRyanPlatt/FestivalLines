# Festival Lines

This is a project for showing off a festival lineup in a way that feels a bit more alive than a plain old static page. The idea is to keep things smooth, easy to explore, and a little more fun to browse.

## What’s in it

- React + Vite for the frontend setup
- GSAP for the animation engine
- @gsap/react for using GSAP in a React-friendly way
- Lenis for smooth scrolling

## Getting started

From the frontend folder, run:

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser and you should be good to go.

## Notes

Nothing too fancy here, just a simple app with some motion and smooth scroll to make the lineup feel a bit nicer to use.
