# Festival Lineup
---
A webapp displaying festival lineups utilizing Lenis- Smooth Sroll. Used for DevOps Course

This Project aims to create a festival lineup application drifting away from traditional web pasted pdfs with newer technologies like Lenis Smooth-Scroll with React. 
This UI driven approach will ease UX with quicker Festival Stage Lookups.

- C# Backend
- React/TS front end
	- Lenis Scroll
- Postgre SQL
